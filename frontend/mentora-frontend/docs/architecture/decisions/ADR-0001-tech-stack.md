# ADR-0001: Технологический стек

## Статус

Принято

## Контекст

Нужен фронтенд-стек для LMS-платформы Mentora с тремя ролями пользователей
(Student, Instructor, Admin), редактором курсов, видеоплеером, оплатой и
аналитикой — с упором на типобезопасность и удобство AI-агентной
разработки (явные конвенции, минимум "магии").

## Решение

- **React 19** — актуальная версия, поддержка Actions/hooks-обновлений.
- **Vite** — быстрый dev-сервер и сборка, простая конфигурация алиасов.
- **TypeScript (strict)** — обязателен для всех файлов, `no any` без
  обоснования.
- **TanStack Router** — типобезопасный файловый роутинг (см. ADR-0003).
- **TanStack Query** — единственный источник server-state (см. ADR-0004
  про причины отделения от Zustand).
- **Zustand** — минималистичный UI-state менеджер, без boilerplate Redux.
- **Zod** — валидация форм и API-ответов на границе приложения.
- **Tailwind v4** — утилитарный CSS (см. ADR-0002).
- **shadcn/ui** (new-york style) — база компонентов, копируется в
  `src/shared/ui/`, не npm-зависимость — полный контроль над кодом.

## Последствия

- Высокая типобезопасность от API до UI (Zod + orval codegen + TS strict).
- Явные границы ответственности (server-state vs UI-state) снижают
  вероятность рассинхронизации данных.
- shadcn/ui требует дисциплины: компоненты добавляются только через CLI,
  не пишутся вручную (иначе теряется смысл единого источника).
