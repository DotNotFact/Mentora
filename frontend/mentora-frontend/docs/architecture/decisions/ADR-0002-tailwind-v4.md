# ADR-0002: Tailwind v4

## Статус

Принято

## Контекст

Нужен подход к стилизации, совместимый с shadcn/ui (new-york style),
поддерживающий CSS-переменные для темизации и не требующий отдельного
`postcss.config.js`/тяжёлой конфигурации.

## Решение

Использовать Tailwind v4 через `@tailwindcss/vite` (нативный Vite-плагин,
без PostCSS-прослойки). Токены темы объявляются CSS-first через `@theme`
в `src/styles/globals.css`, а не только в `tailwind.config.ts`.
`tailwind.config.ts` остаётся для `content`-путей и совместимости с
инструментами, ожидающими JS/TS-конфиг (например, некоторые shadcn-плагины).

## Последствия

- Никаких inline styles, CSS modules или styled-components — только
  Tailwind-классы (см. CLAUDE.md → Красный список).
- CSS-переменные в одном месте (`globals.css`) — единый источник для
  цветов, используемых и Tailwind-утилитами, и произвольным CSS при
  необходимости.
- Обновления Tailwind v4 могут менять `@theme`-синтаксис быстрее, чем
  v3-эра — при апгрейде сверяться с changelog перед мержем.
