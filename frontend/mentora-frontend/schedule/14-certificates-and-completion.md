# 14 — Сертификаты о прохождении курса

Статус: [ ] не начата

## Контекст

Найдено при подготовке (в ответ на "Додумай мой продукт", 2026-08-05):
главная страница (`src/app/routes/index.tsx`) обещает в своём же
description "...получайте сертификаты", но фичи сертификатов не
существует нигде в кодовой базе — ни компонента, ни роута, ни поля в
`openapi/openapi.yaml`. Это не просто отсутствующая common-parity
фича (есть у Coursera/Udemy/Stepik) — это нарушенное обещание
собственного маркетингового текста платформы.

## Цель

Студент, завершивший курс на 100% (`features/enrollment` уже
отслеживает прогресс — уточнить точное поле при реализации), получает
сертификат: просматриваемый в приложении (`/certificates/$id` или
внутри `/my-courses`) и скачиваемый как PDF/изображение с уникальным
проверочным ID.

## Ветка

`feature/14-certificates-and-completion`

## Шаги

1. Контракт: добавить в `openapi/openapi.yaml` `Certificate` (id,
   userId, courseId, issuedAt, verificationCode) + эндпоинт
   `GET /certificates/{id}` и публичный `GET /certificates/verify/
{code}` (для проверки подлинности третьей стороной без авторизации).
   Перегенерировать клиент.
2. `features/enrollment` (или новый `features/certificates`, если
   заводить отдельный модуль оправдано объёмом) — хук, который
   инициирует выдачу сертификата при достижении 100% прогресса.
3. UI: карточка сертификата в `/my-courses` для завершённых курсов,
   страница просмотра с данными курса/студента/датой, кнопка "Скачать
   PDF" (например `@react-pdf/renderer` или canvas-рендер + экспорт —
   выбрать при реализации, свериться с уже используемыми зависимостями
   перед добавлением новой).
4. Публичная страница верификации `/certificates/verify/$code` —
   доступна без аутентификации (гостевой доступ, согласуется с
   schedule/13 — это ровно тот тип контента, который гость должен
   видеть).
5. Скриншот-гейт: карточка сертификата, страница сертификата, страница
   верификации — 375/768/1280px.

## Дизайн-заметки

Сертификат — репрезентативный документ, должен визуально выделяться из
обычного UI платформы (более "печатный"/формальный layout — рамка,
типографика для официального документа), не выглядеть как ещё одна
dashboard-карточка. Использовать Space Grotesk/Fira Code из schedule/10,
если она на момент реализации уже выполнена.

## Критерии готовности

- Прохождение курса на 100% автоматически создаёт сертификат (без
  ручного действия администратора).
- PDF скачивается и содержит имя студента, название курса, дату,
  verification code.
- Публичная страница верификации подтверждает подлинность по коду без
  необходимости входа в аккаунт.
- `yarn verify` зелёный, e2e-тест на happy path (завершить курс →
  увидеть сертификат → скачать).

## Не входит

Соцсети-шеринг ("Поделиться в LinkedIn"), кастомизация дизайна
сертификата преподавателем, NFT/блокчейн-верификация — не по объёму
этой задачи.
