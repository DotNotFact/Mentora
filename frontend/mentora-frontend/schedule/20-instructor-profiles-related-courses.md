# 20 — Публичный профиль инструктора + похожие курсы

Статус: [ ] не начата

## Контекст

Полный аудит проекта (2026-08-06). `instructorName` на `CourseCard` и
`course-detail.tsx` — статичный текст, никуда не ведёт. Нет способа
посмотреть все курсы одного инструктора или узнать о нём больше. На
`course-detail.tsx` также нет "Похожих курсов" — типичный элемент
discovery/cross-sell на любой торговой/образовательной платформе,
удерживающий пользователя на сайте вместо ухода после просмотра одной
страницы.

## Цель

Клик по имени инструктора на `CourseCard`/`course-detail.tsx` ведёт на
публичную страницу `/instructors/$instructorId` — аватар, имя, био,
сетка всех его курсов (переиспользует `CourseCard`), агрегированный
рейтинг по всем курсам (если `schedule/17` уже выполнена). На
`course-detail.tsx` — секция "Похожие курсы" (та же категория,
исключая текущий).

## Ветка

`feature/20-instructor-profiles-related-courses`

## Шаги

1. `openapi.yaml`: расширить `User` (или отдельный
   `InstructorProfile`) полями `bio`, `avatarUrl`; `GET /instructors/
{id}` (публичный, без авторизации — согласуется с
   `schedule/13-roles-and-collaboration.md`: гость должен видеть
   публичный контент). Перегенерировать.
2. Роут `/instructors/$instructorId` + `InstructorProfile` компонент —
   шапка (аватар, имя, био), сетка курсов инструктора (переиспользует
   `CourseCard`, паттерн из `AGENTS.md` → "Architecture discovery
   gate" — не дублировать карточку курса).
3. `course-card.tsx`, `course-detail.tsx`: `instructorName` → `<Link
to="/instructors/$instructorId">`.
4. `course-detail.tsx`: секция "Похожие курсы" — переиспользовать
   `useCourses` с фильтром по текущей категории, исключить текущий
   курс, ограничить 3-4 карточками, staggered-появление
   (`aaa-ui-polish`, как в `CourseGrid`).
5. Скриншот-гейт: страница профиля инструктора, секция "Похожие
   курсы" на `course-detail` — 375/768/1280px.

## Дизайн-заметки

Профиль — не отдельный "дизайн-язык", те же токены/паттерны, что
каталог курсов (сетка `CourseCard`, тот же grid-gap). Аватар — если
`avatarUrl` отсутствует — инициалы на цветном фоне (паттерн уже
частично есть в идее "иконка в круглой подложке" из empty-state
canonical pattern, адаптировать).

## Критерии готовности

- Клик по имени инструктора в любом месте приложения ведёт на его
  профиль.
- Профиль показывает все курсы инструктора через тот же `CourseCard`.
- "Похожие курсы" не показывает текущий курс среди похожих.
- Гость (неаутентифицированный) может открыть профиль инструктора
  (публичная страница).

## Не входит

Редактирование профиля самим инструктором (UI для этого — отдельная
задача, профиль сейчас read-only/сидируется), аналитика инструктора на
этой странице (уже есть `/dashboard/instructor`, не дублировать).
