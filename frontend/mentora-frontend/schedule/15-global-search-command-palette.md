# 15 — Глобальный поиск + Command Palette (Cmd+K)

Статус: [ ] не начата

## Контекст

Полный аудит проекта (2026-08-06, по запросу администратора — "проанализируй
проект полностью и добавь задач, чтобы опережать своё время"). Найдено:
сайтового поиска нет вообще — `schedule/12-dashboard-shell-navigation.md`
явно вынес "Поиск по сайту" в "Не входит". Каталог фильтрует только
локально по `search`-параметру. Ни одного способа быстро перейти между
разделами/выполнить действие без мыши — то, что есть в любом
современном SaaS-продукте (Linear, Vercel, GitHub, Notion — везде
`Cmd+K`/`Ctrl+K` открывает command palette).

## Цель

`Cmd+K`/`Ctrl+K` из любого места аутентифицированного приложения
открывает command palette: поиск курсов по названию, быстрые переходы
по пунктам меню (те же, что в `Sidebar`, по роли), быстрые действия
(переключить тему на одну из 5 готовых — schedule/11, выйти).

## Ветка

`feature/15-global-search-command-palette`

## Шаги

1. Добавить shadcn `command` компонент (`npx shadcn@latest add command`
   — обёртка над `cmdk`).
2. `CommandPalette` — модальный оверлей, открывается по `Cmd+K`/`Ctrl+K`
   (`useEffect` с `keydown`-листенером на уровне `AppProvider`, once),
   закрывается по `Esc`/выбору/клику вне.
3. Секция "Курсы" — поиск по уже закэшированным через TanStack Query
   данным каталога (переиспользовать `useCourses`/`GET /courses?search=`,
   не заводить отдельный эндпоинт) — debounce как в существующем
   `course-filters.tsx`.
4. Секция "Разделы" — переиспользовать `NAV_ITEMS`/`navItemsForRole` из
   `app/layout/nav-items.ts` (schedule/12) — те же пункты, что в
   Sidebar, никакого отдельного списка.
5. Секция "Действия" — переключить тему (5 вариантов из
   `shared/config/themes.ts`, schedule/11), "Выйти".
6. Клавиатурная навигация: стрелки вверх/вниз между результатами,
   `Enter` — перейти/выполнить, `Esc` — закрыть. Индикатор в UI (иконка
   в `TopBar` или подсказка "⌘K"), чтобы функциональность была
   discoverable не только для тех, кто уже знает шорткат.
7. Скриншот-гейт: открытая палитра с результатами поиска, 375/768/1280px.

## Дизайн-заметки

Анимация открытия/закрытия — `animate-in fade-in zoom-in-95` (теперь
реально работает, `tw-animate-css` установлен в schedule/10). Overlay —
тот же паттерн, что elevation-таблица `mentora-design/SKILL.md`
предписывает для диалогов (`shadow-xl`, максимальный уровень).

## Критерии готовности

- `Cmd+K` (Mac) и `Ctrl+K` (Windows/Linux) оба открывают палитру из
  любого экрана.
- Ввод текста фильтрует курсы и разделы одновременно.
- Полная клавиатурная навигация без мыши.
- Список разделов совпадает с текущими правами роли (не показывает
  недоступные пункты).

## Не входит

Полнотекстовый поиск по содержимому уроков (нет бэкенд-индекса для
этого), история недавних поисков/переходов, поиск по инструкторам
(появится органично после schedule/20).
