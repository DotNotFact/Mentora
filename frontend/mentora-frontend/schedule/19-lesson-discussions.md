# 19 — Обсуждения/Q&A под уроком

Статус: [ ] не начата

## Контекст

Полный аудит проекта (2026-08-06). В плеере обучения
(`features/enrollment`) нет никакого способа задать вопрос по уроку —
ни студенту другому студенту, ни студенту инструктору. Udemy (вкладка
Q&A), Coursera (форумы обсуждений) — это стандартная часть любой
серьёзной образовательной платформы, у Mentora её нет вообще.

## Цель

Под каждым уроком — секция обсуждения: записанные на курс студенты
могут оставить вопрос/комментарий, любой записанный студент или
инструктор курса может ответить. Ответы инструктора визуально
выделены.

## Ветка

`feature/19-lesson-discussions`

## Шаги

1. `openapi.yaml`: `Comment` (id, lessonId, userId, userName, userRole,
   parentId?: string, body, createdAt), `GET /lessons/{id}/comments`,
   `POST /lessons/{id}/comments`. Вложенность — один уровень (ответ на
   комментарий), не полное дерево — сознательное ограничение объёма.
2. `features/enrollment/components/lesson-discussion.tsx` —
   `CommentForm` (textarea + отправить, доступно только записанным),
   `CommentThread` (список комментариев, ответы — вложены с отступом
   один уровень).
3. Ответы от пользователя с `userRole === 'instructor'` И
   `instructorId` курса совпадает с автором — бейдж "Автор курса"
   (`Badge variant="secondary"`, не `accent` — тот зарезервирован под
   CTA/прогресс/рейтинги schedule/17).
4. Разместить секцию под/рядом с содержимым урока в плеере обучения
   (`learning/$courseId` роут) — вкладка или секция ниже видео, решить
   по месту, не перегружая и так насыщенный экран плеера.
5. Скриншот-гейт: секция с несколькими комментариями и одним ответом
   от инструктора — 375/768/1280px.

## Дизайн-заметки

Простой плоский список с одним уровнем вложенности — не chat-виджет,
не real-time (обновление — при повторном заходе/ручном refetch, не
WebSocket). Пустое состояние ("Пока нет вопросов — задайте первый")
по канону `mentora-design/SKILL.md` empty-state паттерна.

## Критерии готовности

- Только записанные на курс пользователи видят форму и могут писать.
- Ответы инструктора курса визуально отличимы от ответов студентов.
- Комментарии переживают обновление страницы (не теряются, мок хранит
  состояние на сессию теста аналогично остальным мокам).
- Разумный лимит/пагинация при длинных тредах (не рендерить сотни
  комментариев одним списком без ограничения).

## Не входит

Real-time обновления (poll/refetch по действию, не push), голосование
"полезно"/сортировка по полезности, модерация/жалобы, форматированный
текст в комментариях (только plain text).
